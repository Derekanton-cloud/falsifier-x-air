# FALSIFIER-X AIR — Research Prototype v0.1

Graph-Based AI System for Flight Disruption Analysis, Cause Discovery, and Recovery.

Research loop:
Prediction -> Uncertainty/OOD -> Structural Adequacy -> Localisation ->
Constrained Mechanisms -> Active Experiment -> Digital Twin ->
Falsification -> Model Repair -> Recovery.

This prototype demonstrates the research logic before replacing the baseline
predictor with the full spatio-temporal GNN.

Run:
    pip install -r requirements.txt
    python -m falsifier_x_air.demo

Research boundary:
This is a controlled research prototype, not evidence of a real-world causal
discovery. Real aviation validation is a later phase.
